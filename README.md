# OAI Model Reliability Explorer

A static educational research companion. The repository root is the complete website; no build or server dependency is needed. Run `node check.mjs` to verify all 105 synthetic examples, deferral policies, and consistency with frozen aggregate results.

The toy simulator is explicitly separate from OAI model fitting. Its invented expectations and error formula are fully disclosed in the interface. No participant data, clinical model, medical-input collection, external analytics, or persistence is included.

Actual evidence is drawn only from the sanitized research repository's risk-coverage aggregate table. Study authors are Karthigeyan and Tang. ChatGPT/Codex assisted with the design, implementation, documentation, and checks of this companion in October 2026.

Live explorer: https://ksricharan7.github.io/oai-model-reliability/

Hosted as a static site on GitHub Pages. No custom domain or paid hosting is required.
